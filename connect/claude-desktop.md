# Claude Desktop에서 연결하기

코드·설정 파일 없이 화면에서 추가합니다. (Claude 무료 계정도 커스텀 커넥터를 지원합니다 —
플랜에 따라 메뉴 위치가 다를 수 있습니다.)

1. Claude Desktop → **설정(Settings)** → **커넥터(Connectors)**
2. **커스텀 커넥터 추가(Add custom connector)** 클릭
3. 이름: `대전 중구 행정정보` (자유), URL:
   ```
   https://djmcp.up.railway.app/junggu/mcp
   ```
4. 추가 후 새 대화에서 검색 도구 아이콘(🔧)에 도구 15종이 보이면 성공

## 확인 질문

```
중구 최근 고시공고 중 주차 관련을 찾아줘
```

응답에 근거 문서(source·URL)가 인용되면 정상 동작입니다. 근거 없이 답하면 그건 이 서버가 아니라
모델의 일반 지식입니다 — 이 서버의 모든 사실 응답에는 출처가 붙습니다.

## 참고

- 인증 화면은 없습니다(익명·무등록). OAuth를 묻는 클라이언트라면 "인증 없음"을 선택하세요.
- 웹 브라우저의 claude.ai에서도 같은 방법으로 커넥터를 추가할 수 있습니다(설정 → 커넥터).
